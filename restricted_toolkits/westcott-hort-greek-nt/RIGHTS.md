# Rights — westcott-hort-greek-nt

- **Work:** Westcott & Hort, *The New Testament in the Original Greek* (1881).
- **Digitization:** byztxt `textonly` (unaccented, Robinson digitization).
- **Rightsholder:** none — **public domain** (Westcott d.1901, Hort d.1892; printed 1881).
- **Status:** public-domain. byztxt states **"Public Domain. Copy freely."**
- **Distributable by this archive:** yes (it is already published in the public Reading Room).

## Why it lives here
This is the **proof-of-concept** package. It is intentionally a public-domain text run
through the *restricted/local* pipeline (gitignored output, structural validation,
local-only reader) so the toolkit machinery and guardrails can be proven end-to-end with
**zero legal exposure** before any in-copyright text is ever attempted.

## This toolkit does NOT
- bundle or distribute the Greek text, any excerpt, or any sample;
- bypass DRM, paywalls, or logins (none exist for this PD source);
- scrape any site against its terms of service.

The optional `--fetch` path is allowed only because the byztxt source is public domain.
The default path is `--input`: you supply your own copy of the PD `textonly` files.
